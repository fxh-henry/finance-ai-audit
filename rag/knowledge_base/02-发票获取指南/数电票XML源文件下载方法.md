# 数电票XML源文件下载方法

---

## 一、为什么必须下载XML

### 政策依据
2025年5月，财政部、税务总局等九部门联合印发《关于推广应用电子凭证会计数据标准的通知》（财会〔2025〕9号），明确规定：

> **数电发票报销入账归档以含数字签名的XML文件为准。**

### 三种格式的区别

| 格式 | 作用 | 能否作为报销归档原件 |
|---|---|---|
| **XML** | 含数字签名的结构化数据，法定原件 | ✅ 是 |
| PDF | 预览件，用于查看和打印 | ❌ 否 |
| OFD | 预览件，用于查看和打印 | ❌ 否 |

### 重要提醒
- 只保存PDF = 归档不合规
- 无论是否打印纸质件，都必须保存XML源文件
- 2028年1月1日前，所有企业会计软件必须完成XML适配

## 二、XML下载的三种方法

### 方法一：直接向开票方索要（最简单，推荐员工使用）

**适用场景**：个人报销，发票数量少

**操作步骤**：
1. 消费后，主动要求商家/开票方提供XML格式的电子发票
2. 开票方开具成功后，可通过以下方式交付：
   - 直接发送XML文件到你的邮箱
   - 提供二维码，扫码下载XML
   - 发送到你的税务数字账户（自动交付）

**注意**：
- 不要只收PDF，一定要同时索要XML
- 商家说"只有PDF"时，告知对方数电票必须提供XML

---

### 方法二：电子税务局税务数字账户下载（财务人员使用，最权威）

**适用场景**：企业财务批量下载、员工个人也可登录查询

**操作步骤**：

#### 第一步：登录电子税务局
1. 打开当地电子税务局网站（如江苏省电子税务局）
2. 使用企业账号/个人账号登录

#### 第二步：进入税务数字账户
```
我要办税 → 税务数字账户
```

#### 第三步：进入发票查询
```
发票查询统计 → 全量发票查询
```

#### 第四步：筛选发票
- 查询类型选择"取得发票"（收到的发票）
- 设置开票日期范围
- 可按发票类型、销售方等条件筛选

#### 第五步：下载XML
1. 在查询结果中找到目标发票
2. 点击发票右侧的【交付】或【详情】
3. 在详情页点击【下载XML】按钮
4. 保存XML文件到本地

**批量下载**：
- 勾选多张发票，点击【批量交付】或【批量下载】
- 可一次性导出多张XML文件

---

### 方法三：第三方工具批量下载（适合月底集中报销）

**适用场景**：发票数量多，需要批量处理

**常见工具**：
- 宜盟报销查重工具（小程序）
- 每刻报销、合思等报销系统
- 其他支持XML下载的财务SaaS

**操作步骤**（以小程序为例）：
1. 打开小程序，进入【XML下载】功能
2. 批量导入发票PDF或发票号码
3. 系统自动获取对应的XML原件
4. 一键批量导出所有XML文件

## 三、XML文件的命名和保存建议

### 命名规范
建议统一命名格式，方便管理：
```
发票号码_销售方名称_金额.xml
示例：26322000007048122601_宿迁市泗阳县锦泓服装加工有限公司_36636.00.xml
```

### 保存要求
1. XML文件必须与报销单一起提交
2. 财务审核时需校验XML数字签名是否有效
3. 归档时XML文件作为电子档案长期保存
4. 建议同时保存PDF预览件，方便人工查看

## 四、常见问题

### Q1：只有PDF没有XML怎么办？
A：有两种方式：
1. 联系开票方重新提供XML文件
2. 登录电子税务局税务数字账户，按发票号码查询并下载XML

### Q2：XML文件打开是乱码？
A：XML是纯文本格式，用记事本、浏览器、VS Code等都可以打开。如果显示乱码，可能是编码问题，用浏览器打开一般可以正常显示。

### Q3：XML文件可以修改吗？
A：绝对不能修改！XML含有数字签名，修改后签名失效，发票无效。系统会自动校验XML签名的完整性。

### Q4：高铁票、飞机票有XML吗？
A：有。铁路电子客票、航空运输电子客票行程单都已纳入电子凭证会计数据标准，支持XML格式。

### Q5：个人能登录电子税务局下载XML吗？
A：可以。个人实名注册电子税务局后，可查询本人作为购买方的数电发票并下载XML。

## 五、本系统的处理方式

智能报销审核系统支持：
1. **XML优先解析**：上传XML文件，直接读取结构化数据，准确率100%
2. **PDF兜底识别**：只有PDF时，用坐标法提取票面信息
3. **XML校验**：自动校验XML数字签名是否有效、发票是否作废/红冲
4. **自动重命名**：系统自动按规范重命名XML文件，方便归档
