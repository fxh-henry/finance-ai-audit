# 报销帮助中心知识库

本知识库用于帮助企业员工完成报销全流程，包含发票基础知识、获取指南、报销流程、费用标准、常见问题和违规案例六大模块。

---

## 知识库结构

```
知识库/
├── 01-发票基础知识/          # 发票种类、数电票概念、XML法定地位
├── 02-发票获取指南/          # 各种发票的获取/下载方法
├── 03-报销流程指南/          # 报销流程、审批权限、时间规定
├── 04-费用报销标准/          # 各类费用的报销标准
├── 05-常见问题FAQ/           # 报销中常见问题解答
└── 06-违规案例警示/          # 典型违规案例及后果
```

## 使用说明

1. **员工报销前**：先阅读"02-发票获取指南"，确保取得合规票据
2. **填写报销单时**：查阅"04-费用报销标准"，确认费用符合标准
3. **遇到问题时**：搜索"05-常见问题FAQ"，快速找到答案
4. **财务审核时**：参考"06-违规案例警示"，识别风险票据
